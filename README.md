# resume-auto

Tampermonkey 用户脚本：BOSS直聘筛选批量投递 + 自定义招呼语 + 浮层终端。

## 安装
1. 安装[篡改猴](https://www.tampermonkey.net/)
2. `npm install && npm run build`
3. 将 `dist/resume-auto.user.js` 导入篡改猴

## 使用
1. 登录 BOSS直聘，打开职位列表（先用站内筛选缩小范围）
2. 右下角浮层 →「配置」填写筛选与招呼语
3. 「开始」；可暂停/停止/导出日志

### 配置字段与「不填」时的行为

配置保存在浏览器本地（篡改猴 GM 存储），刷新后仍在。

| 字段 | 默认 | 留空 / 默认时会发生什么 |
|------|------|------------------------|
| **职位名包含** | 空 | **不过滤职位名**，列表里扫到的岗位都会进入后续筛选（仍会受公司/薪资/去重限制） |
| **公司名包含** | 空 | **不限定公司**，任何公司都可通过 |
| **公司名排除** | 空 | **不排除任何公司**；填「外包,人力」等逗号分隔后，公司名含这些词的会跳过 |
| **描述排除词** | 空 | 不按描述过滤。**注意：当前版本 extract 尚未抓取职位描述**，该字段暂不生效（界面可配，属预留） |
| **薪资下限 (K)** | `0` | 表示**不设下限**。仅当上下限都为 0 时完全忽略薪资；只填下限时上限视为不限 |
| **薪资上限 (K)** | `0` | 表示**不设上限**。薪资区间与期望有交集才通过（如 `8-12K` 对 15–40 会被排除） |
| **日配额** | `100` | 当日最多成功投递 100 条；达到后整批停止并提示。可改小（建议试跑先设 5–10） |
| **招呼语** | 空 | **只投递、不发送自定义招呼语**（仍会走 BOSS 默认「立即沟通」流程）。填写后，投递成功再尝试在会话里发送该文案 |
| **无薪资跳过** | 未勾选 | 面议/无薪资文案的岗位**仍会投**。勾选后，解析不出薪资区间且未配薪资条件时会跳过 |

### 推荐最小配置（试跑）

1. **职位名包含**：你的方向，如 `前端,React,Vue`
2. **公司名排除**：如 `外包,外派,人力`
3. **日配额**：先 `5`
4. **招呼语**：一句简短自我介绍（可先空着只测投递）
5. 点「开始」，盯日志：扫描数 → 筛选通过 → 每条 `ok/skip/fail`

### 未配置时点「开始」会怎样？

- 会**对当前列表页扫到的全部岗位**（去重、未超配额）尝试投递  
- 没有关键词限制时可能投得过宽，**务必先缩小站内筛选或填「职位名包含」**  
- 已投过的会跳过；当日配额满 100 会停
