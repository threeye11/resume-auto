# resume-auto

Tampermonkey 用户脚本：招聘站筛选批量投递 + 浮层终端。

**已适配：** BOSS直聘 · 前程无忧（we.51job.com）

## 安装
1. 安装[篡改猴](https://www.tampermonkey.net/)
2. `npm install && npm run build`
3. 将 `dist/resume-auto.user.js` 导入篡改猴

## 使用

### 推荐流程（站内粗筛 + 脚本精筛）

脚本**不会**替你点站点顶部的城市/行业等下拉框，也**不会**自己翻页抓全站。它只处理**当前列表页已渲染的 DOM**：读卡片文字 → 规则匹配 → 模拟点击投递按钮。

```text
① 你在目标站「职位搜索」列表页做站内粗筛
        ↓
② 脚本配置里做第二层精筛（关键词 / 排除公司 / 薪资）
        ↓
③ 点「开始」→ 扫描 → 已投跳过(指针++) → 投递 → 弹窗「留在此页」
```

**步骤：**

1. 登录目标站，打开职位搜索列表页  
   - BOSS：`zhipin.com` 职位列表  
   - 51job：`we.51job.com/pc/search`
2. **先用站内筛选**收窄范围
3. 右下角 `resume-auto` →「配置」填规则；试跑日配额建议 `5`
4. 「开始」；盯日志：`待投 N 条` → `#i … ok`
5. 可暂停/停止/导出；折叠球可拖、显示 RUN/PAU 等状态

**BOSS 注意：** 点「立即沟通」会弹「已向BOSS发送消息」，脚本**只点「留在此页」**，不会进聊天。招呼内容以 BOSS「消息→设置招呼语」为准。

**51job 注意：** 按卡片上的橙色「投递」文案匹配；DOM 改版时改 `src/platforms/w51job/selectors.js`。列表页无会话框，脚本内招呼语在 51job 不生效。

**通用：**
- 只处理当前已加载列表；滚动/翻页后再点开始
- 已投去重 + 日配额；配置里可「清除已投记录」「重置今日配额」
- 扫描 0 条时用 DevTools 核对对应 `platforms/*/selectors.js`

### 配置字段与「不填」时的行为

### 配置字段与「不填」时的行为

配置保存在浏览器本地（篡改猴 GM 存储），刷新后仍在。

| 字段 | 默认 | 留空 / 默认时会发生什么 |
|------|------|------------------------|
| **职位名包含** | 空 | **不过滤职位名**，列表里扫到的岗位都会进入后续筛选（仍会受公司/薪资/去重限制） |
| **公司名包含** | 空 | **不限定公司**，任何公司都可通过 |
| **公司名排除** | 空 | **不排除任何公司**；填「外包,人力」等逗号分隔后，公司名含这些词的会跳过 |
| **描述排除词** | 空 | 不按描述过滤。**注意：当前版本 extract 尚未抓取职位描述**，该字段暂不生效（界面可配，属预留） |
| **薪资下限 (K)** | `0` | 表示**不设下限**。仅当上下限都为 0 时完全忽略薪资；只填下限时上限视为不限 |
| **薪资上限 (K)** | `0` | 表示**不设上限**。薪资区间与期望有交集才通过（如 `8-12K` 对 15–40 会被排除） |
| **日配额** | `100` | 当日最多成功投递 100 条；达到后整批停止并提示。可改小（建议试跑先设 5–10） |
| **招呼语** | 空 | 点「立即沟通」时，**BOSS 会发送你在「消息 → 设置招呼语」里配好的默认文案**。脚本里再填「招呼语」只在能打开会话输入框时补发；列表页批量投递一般用不到，可留空 |
| **无薪资跳过** | 未勾选 | 面议/无薪资文案的岗位**仍会投**。勾选后，解析不出薪资区间且未配薪资条件时会跳过 |

### 推荐最小配置（试跑）

1. **职位名包含**：你的方向，如 `前端,React,Vue`
2. **公司名排除**：如 `外包,外派,人力`
3. **日配额**：先 `5`
4. **招呼语**：一句简短自我介绍（可先空着只测投递）
5. 点「开始」，盯日志：扫描数 → 筛选通过 → 每条 `ok/skip/fail`

### 未配置时点「开始」会怎样？

- 会**对当前列表页扫到的全部岗位**（去重、未超配额）尝试投递  
- 没有关键词限制时可能投得过宽，**务必先缩小站内筛选或填「职位名包含」**  
- 已投过的会跳过；当日配额满 100 会停
