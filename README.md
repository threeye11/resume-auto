# resume-auto

Tampermonkey（篡改猴）用户脚本：在浏览器里对招聘站列表页做**筛选、去重、限配额批量投递**，右下角带浮层终端实时看日志。

**已适配平台**

| 平台 | 入口 | 投递动作 |
|------|------|----------|
| BOSS直聘 | [www.zhipin.com](https://www.zhipin.com) 职位列表 | 「立即沟通」→ 弹窗点「留在此页」 |
| 前程无忧 51job | [we.51job.com/pc/search](https://we.51job.com/pc/search) | 橙色「投递」→ 关确认弹窗（不点「去聊聊」） |

---

## 安装

### 方式 A：本地构建（推荐）

```powershell
npm install
npm run build
```

1. 安装 [篡改猴 Tampermonkey](https://www.tampermonkey.net/)
2. 打开扩展 →「添加新脚本」，或把 `dist/resume-auto.user.js` 拖入
3. 保存后刷新招聘站页面，右下角应出现 `resume-auto` 浮层

### 方式 B：开发预览终端 UI

```powershell
npm run dev
```

浏览器打开 Vite 提示的本地地址，可单独预览浮层（mock 日志）。

## 使用教程

### 核心思路：站内粗筛 + 脚本精筛

脚本**不会**替你点城市/行业下拉框，也**不会**无脑爬全站。它只读取**当前列表页已渲染的 DOM**：

```text
你在目标站用官方筛选收窄列表
        ↓
脚本配置里再按关键词 / 排除公司 / 薪资 过滤
        ↓
点「开始」
  扫描 → 已投跳过(指针++) → 待投队列
  → 点投递 → 处理弹窗 → （可选自动翻页）
```

### 标准步骤

1. **登录**目标站，打开职位**搜索列表页**
2. 用站内筛选收窄：城市、职类、薪资、经验等（列表越短越好）
3. 点右下角浮层 **「配置」**
   - 职位名包含：如 `嵌入式,硬件,单片机`
   - 公司名排除：如 `外包,外派,人力`
   - 日配额：**试跑先设 5**
   - 自动翻页：需要连翻多页时勾选，并设「最多翻到第几页」
4. 点 **「开始」**，看日志：
   - `第N页 · 待投 X 条`
   - `#i 职位@公司 ok`
   - 配额、进度
5. 可随时 **暂停 / 停止 / 导出** 日志

### 浮层终端

| 操作 | 说明 |
|------|------|
| 开始 / 暂停 / 停止 | 主控制；暂停后再点开始 = 继续 |
| 配置 | 筛选、配额、自动翻页、维护按钮 |
| 导出 | 下载当前日志 txt |
| 折叠 | 收成小球，可拖动；球上短码：RUN 投递中 / PAU 暂停 / END 结束 / IDLE 空闲 |
| □ / 重叠双框 | 最大化 / 向下还原 |

### 配置字段（留空时的默认行为）

配置按**站点隔离**（BOSS 与 51job 的已投列表、日配额、筛选互不影响），存篡改猴 GM 存储。

| 字段 | 默认 | 留空 / 默认 |
|------|------|-------------|
| 职位名包含 | 空 | 不过滤职位名 |
| 公司名包含 | 空 | 不限公司 |
| 公司名排除 | 空 | 不排除 |
| 描述排除词 | 空 | 预留（当前 extract 不抓描述） |
| 薪资下限/上限 (K) | `0` | 忽略薪资条件 |
| 日配额 | `100` | 当日最多成功投递次数 |
| 招呼语 | 空 | BOSS：以站内「消息→设置招呼语」为准；51job：列表无输入框，基本不发 |
| 无薪资跳过 | 关 | 面议岗也会投 |
| 自动翻页 | 关 | 只投当前页 |
| 最多翻到第几页 | `3` | 开自动翻页时的上限 |

配置面板底部维护：

- **清除已投记录** — 误记/重测时清空去重库  
- **重置今日配额** — 把当日已投次数清零  

### BOSS直聘 说明

- 点「立即沟通」后会弹 **「已向BOSS发送消息」**，脚本**只点「留在此页」**，不会跳进聊天打断批量
- 打招呼内容请在 BOSS **「消息 → 设置招呼语」** 里配置
- 列表多为无限滚动：勾选自动翻页会尝试滚到底加载更多

### 51job（前程无忧）说明

- 只点卡片上的 **「投递」**；**不会点「去聊聊」**（会拉微信扫码，脚本无法继续）
- 投递后若出现「微信扫码与我聊聊吧」等弹层，脚本会尝试关闭（ESC / 关闭按钮）
- 分页在列表底部：勾选 **自动翻页**，当前页投完后点「下一页」，用页码变化判断是否成功
- 跑完一轮后可改大「最大页数」再点开始；若要从第 1 页重来，先手动点分页「1」

### 扫描为 0 / 按钮点不到

1. 用 DevTools 看职位卡片真实 class  
2. 改对应选择器后重新 build：

| 平台 | 文件 |
|------|------|
| BOSS | `src/platforms/boss/selectors.js` |
| 51job | `src/platforms/w51job/selectors.js` |

## 开发

```powershell
npm test          # core 单测（node --test）
npm run build     # 产出 dist/resume-auto.user.js
npm run dev       # 终端 UI 预览
```

目录要点：

```text
src/
  core/           # 调度、筛选、去重、配额、事件总线（无 DOM）
  platforms/boss/ # BOSS 适配器
  platforms/w51job/ # 51job 适配器
  ui/terminal/    # 浮层终端
  index.user.js   # 按域名选择适配器并挂载
```
