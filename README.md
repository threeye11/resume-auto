# resume-auto

Tampermonkey 用户脚本：招聘站筛选批量投递 + BOSS 聊天页闭环沟通 + PIN 保险库。

**已适配：** BOSS直聘（投递 + 聊天页）· 前程无忧（投递）

---

## 快速使用（5 分钟）

### 1. 安装脚本

```powershell
git clone https://github.com/threeye11/resume-auto.git
cd resume-auto
npm install
npm run build
```

1. 装 [篡改猴](https://www.tampermonkey.net/)
2. 把 `dist/resume-auto.user.js` 拖入扩展，或新建脚本粘贴内容并保存
3. 刷新招聘站，右下角出现 **resume-auto**

### 2. 列表页批量投递

1. 登录 BOSS / 51job，先用**站内筛选**收窄职位
2. 浮层 → **配置**
   - 职位名：`嵌入式,硬件`（逗号分隔）
   - 日配额：先 `5`
   - 可选：自动翻页 + 最大页数
3. **开始** → 看日志 `#i … ok`
4. BOSS 只点「立即沟通」+「留在此页」；51job 只点「投递」

### 3. 聊天页闭环（仅 BOSS）

1. 打开 https://www.zhipin.com/web/geek/chat  
2. 浮层 → 配置 → 保险库：**输入 PIN →「设置 PIN 并加密现有敏感项」**
3. 填简历 Markdown（解锁后保存进保险库）
4. 可选：LLM `baseUrl` / `model` / `apiKey`（如 DeepSeek，OpenAI 兼容）
5. 勾选 **主动问候开关**（`custom` 填 2–3 句；或 `llm`）
6. 可选勾选 **HR回复自动起草** → 有回复时生成草稿，点 **发送**
7. **开始**；超时或手动「锁定」后需再输 PIN

**注意：** PIN 不落盘；忘记 PIN →「重置保险库」并自行轮换 API Key。自动锁定分钟数可配，**上限 30 天**。

## 使用教程

### 核心思路：站内粗筛 + 脚本精筛

脚本**不会**替你点城市/行业下拉框，也**不会**无脑爬全站。它只读取**当前列表页已渲染的 DOM**：

```text
你在目标站用官方筛选收窄列表
        ↓
脚本配置里再按关键词 / 排除公司 / 薪资 过滤
        ↓
点「开始」
  扫描 → 已投跳过(指针++) → 待投队列
  → 点投递 → 处理弹窗 → （可选自动翻页）
```

### 标准步骤

1. **登录**目标站，打开职位**搜索列表页**
2. 用站内筛选收窄：城市、职类、薪资、经验等（列表越短越好）
3. 点右下角浮层 **「配置」**
   - 职位名包含：如 `嵌入式,硬件,单片机`
   - 公司名排除：如 `外包,外派,人力`
   - 日配额：**试跑先设 5**
   - 自动翻页：需要连翻多页时勾选，并设「最多翻到第几页」
4. 点 **「开始」**，看日志：
   - `第N页 · 待投 X 条`
   - `#i 职位@公司 ok`
   - 配额、进度
5. 可随时 **暂停 / 停止 / 导出** 日志

### 浮层终端

| 操作 | 说明 |
|------|------|
| 开始 / 暂停 / 停止 | 主控制；暂停后再点开始 = 继续 |
| 配置 | 筛选、配额、自动翻页、维护按钮 |
| 导出 | 下载当前日志 txt |
| 折叠 | 收成小球，可拖动；球上短码：RUN 投递中 / PAU 暂停 / END 结束 / IDLE 空闲 |
| □ / 重叠双框 | 最大化 / 向下还原 |

### 配置字段（留空时的默认行为）

配置按**站点隔离**（BOSS 与 51job 的已投列表、日配额、筛选互不影响），存篡改猴 GM 存储。

| 字段 | 默认 | 留空 / 默认 |
|------|------|-------------|
| 职位名包含 | 空 | 不过滤职位名 |
| 公司名包含 | 空 | 不限公司 |
| 公司名排除 | 空 | 不排除 |
| 描述排除词 | 空 | 预留（当前 extract 不抓描述） |
| 薪资下限/上限 (K) | `0` | 忽略薪资条件 |
| 日配额 | `100` | 当日最多成功投递次数 |
| 招呼语 | 空 | **留空 = 保留原值**（属保险库字段，不回显）。BOSS 建议以站内「消息→设置招呼语」为准；51job 列表无输入框，基本不发 |
| 无薪资跳过 | 关 | 面议岗也会投 |
| 自动翻页 | 关 | 只投当前页 |
| 最多翻到第几页 | `3` | 开自动翻页时的上限 |

配置面板底部维护：

- **清除已投记录** — 误记/重测时清空去重库  
- **重置今日配额** — 把当日已投次数清零  

### BOSS直聘 说明

- 点「立即沟通」后会弹 **「已向BOSS发送消息」**，脚本**只点「留在此页」**，不会跳进聊天打断批量
- 打招呼内容请在 BOSS **「消息 → 设置招呼语」** 里配置
- 列表多为无限滚动：勾选自动翻页会尝试滚到底加载更多

### 51job（前程无忧）说明

- 只点卡片上的 **「投递」**；**不会点「去聊聊」**（会拉微信扫码，脚本无法继续）
- 投递后若出现「微信扫码与我聊聊吧」等弹层，脚本会尝试关闭（ESC / 关闭按钮）
- 分页在列表底部：勾选 **自动翻页**，当前页投完后点「下一页」，用页码变化判断是否成功
- 跑完一轮后可改大「最大页数」再点开始；若要从第 1 页重来，先手动点分页「1」

### 扫描为 0 / 按钮点不到

1. 用 DevTools 看职位卡片真实 class  
2. 改对应选择器后重新 build：

| 平台 | 文件 |
|------|------|
| BOSS | `src/platforms/boss/selectors.js` |
| 51job | `src/platforms/w51job/selectors.js` |

## 聊天页闭环（BOSS only）

**仅在** `https://www.zhipin.com/web/geek/chat` 生效。jobs 列表页投递结束后日志会提示打开聊天页。

### 配置（chat 页 → 浮层「配置」）

抽屉按四段引导排列，**按顺序填即可**（每段顶部有说明，输入框内的灰色示例在聚焦时淡出）：

| 段 | 字段 | 说明 |
|----|------|------|
| ① | 保险库 | 先设 PIN，之后的敏感项才会加密存放（见下节） |
| ② | 简历 Markdown / 目标岗位 | 仅 `llm` 模式作为上下文；`custom` 不读 |
| ③ | LLM baseUrl / apiKey / model / 模板 | OpenAI 兼容（DeepSeek、通义等）；填完点 **「测试连通性」** 就地看结果 |
| ④ | 主动问候开关 / 问候来源 / 自定义问候 / HR回复自动起草 / 单次上限 / 间隔 | 来源为**下拉**：`custom` 直接发送固定文案；`llm` 每会话生成草稿待确认 |

**「留空 = 保留原值」**：API Key 用掩码框且永不回显，简历、模板、问候文案等保险库字段重开面板时也是空的——保存时空值表示不修改，不会清掉已存内容；要换新 Key 直接粘贴覆盖即可。保存成功后这些输入框会被立即清空。

**安全默认：** 不自动替你发送 LLM 回复；API Key 仅存本地；日志不打印完整 Key；浮层整体在 **Shadow DOM** 内，招聘站页面自身的脚本 `querySelector` 读不到配置输入框。

### 保险库（PIN 加密）

敏感字段（`llm.apiKey`、简历 MD、目标岗位、主动问候文案、招呼语等）可用 **PIN + AES-GCM(256) + PBKDF2(SHA-256, 310000 次)** 加密：

1. 聊天页 → 配置 → **保险库** → 输入 PIN →「设置 PIN 并加密」
2. 日常「解锁」后脚本才能读 API Key / 简历；超时或「锁定」后内存清空
3. 自动锁定分钟数可配（默认 15，**上限 43200 = 30 天**）
4. 「修改 PIN」会换盐并重新加密；「重置保险库」删除密文（**请自行轮换 API Key**）
5. PIN **从不写入** GM/日志；GM 中只有 salt + iv + 密文

设计：`docs/compose/spec/secure-secrets.md`
